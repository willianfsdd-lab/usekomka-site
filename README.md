# Usekomka — Loja Simples

Loja demo para a marca Usekomka (biquínis). Projeto minimalista em HTML/CSS/JS sem back-end.

Como testar localmente:

```bash
# a partir da pasta 'Site Simples'
python -m http.server 8000
# abra http://localhost:8000
```

Funcionalidades:
- Catálogo de produtos com imagens (placeholders externos)
- Carrinho com persistência via localStorage
- Checkout simulado (alert)
