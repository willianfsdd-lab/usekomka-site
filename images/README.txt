Coloque aqui as imagens enviadas pelo Instagram renomeadas conforme abaixo:

- biquini-verde.jpg   (foto 1)
- biquini-nude.jpg    (foto 2)

Adicione também as imagens de cena (opcional) para melhorar o fundo:

- beach.jpg       (fundo principal)
- palm-left.png   (palmeira esquerda, fundo transparente recomendado)
- palm-right.png  (palmeira direita, fundo transparente recomendado)

Se preferir, mantenha as imagens com outro nome e atualize `app.js`, `index.html` ou `main.css` para apontar para os arquivos corretos.
Para baixar automaticamente as imagens de exemplo (Unsplash), execute no PowerShell:

	.\scripts\download-images.ps1

Isso criará os arquivos `beach.jpg`, `palm-left.png` e `palm-right.png` na pasta `images/`.
